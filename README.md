# Vista 3D: Urban Decay

A walkable 3D ruined city under a red radioactive dawn, from the Vista 3D series. Built with three.js (loaded from cdnjs) as a single static page: open `index.html` or deploy the folder as a static site.

Controls: drag to look, WASD to walk, Shift to run, scroll to glide. On phones, left thumb walks and right thumb looks.
